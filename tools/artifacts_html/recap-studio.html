Recap Studio

Video recap ကို အဆင့်လိုက် လုပ်ပါ။ Index၊ script၊ အသံ၊ ပြီးရင် editor app မှာ ဆက်လုပ်ပါ။

အဆင့် 0/4 ပြီးပြီ
1 Video indexအပိုင်းတွေ ဖြတ်ပြီး ဖော်ပြချက် ထုတ်မယ် မပြီးသေး

Video ဖိုင်က ဒီ device ထဲမှာပဲ ဖတ်ပါတယ်။ Frame ပုံတွေကိုပဲ Claude ဆီ ပို့ပါတယ်။ Video မရှိရင် အောက်က မှတ်စုနဲ့ပဲ လုပ်လို့ရပါတယ်။

ရုပ်ရှင်၊ ဇာတ်လမ်းတွဲ video တွေက မူပိုင်ခွင့် ရှိတတ်ပါတယ်။ ကိုယ့်စကားနဲ့ ပြန်ပြောပြတဲ့ ပုံစံ သုံးပြီး၊ တင်မယ့် နေရာရဲ့ စည်းမျဉ်းကို အရင်စစ်ပါ။

2 Script + PromptAI နဲ့ recap စာသား ရေးမယ် မပြီးသေး

တစ်ကြောင်းချင်းကို “mm:ss-mm:ss | စာသား” ပုံစံနဲ့ ထားပါ။ Subtitle ထုတ်ဖို့ ဒီပုံစံ လိုပါတယ်။

Subtitle ကို .txt အဖြစ် သိမ်းပါတယ်။ Editor မှာ သုံးဖို့ ဖိုင်နာမည်ကို .srt လို့ ပြောင်းပါ။ “AI Prompt” ကို တခြား AI tool မှာ paste လုပ်ပြီး script ရေးခိုင်းလို့ရပါတယ်။

3 TTS / အသံScript ကို အသံနဲ့ နားထောင်ကြည့်မယ် မပြီးသေး

Browser အသံက နားထောင်ကြည့်ဖို့ပါ၊ mp3 ဖိုင် မထုတ်ပေးပါဘူး။ mp3 လိုရင် Script ကူးပြီး TTS app သို့မဟုတ် website မှာ ထုတ်ပါ။

4 Edit · Render · SaveEditor app ထဲမှာ ဆက်လုပ်မယ် မပြီးသေး

Video ဖြတ်ဆက်တာ၊ render ထုတ်တာကို ဒီ page မှာ မလုပ်နိုင်ပါဘူး။ Editor app ထဲမှာ လုပ်ပြီး ဒီမှာ အဆင့်ပြီးကြောင်း မှတ်ပါ။
